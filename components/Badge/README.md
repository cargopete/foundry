# Badge

Badges label a row or a state in mono on a wash; the only place a pill radius is allowed.

- Provide: a `<span class="fd-badge">` with one modifier: none (neutral), `--accent` (a protocol, a tag of ours), `--ok`, `--warn`, `--bad`.
- Status badges always carry a word; the colour never stands alone. `--bad` only for bad news: failed, blocked, refused.
- Text on a wash is the ink tone (`accent-ink`, `bad-ink`).
