# ValveRadio

A cathedral valve radio whose lit dial is a live figure on a known scale: a rate, a share, a level.

- Provide: a container with a height and `Foundry.ValveRadio(el, { min, max, value, label, digits? })`; `.set(v)` moves the needle and turns the right-hand knob to match. Needs three@0.149.0.
- The dial prints its scale, the current value and the label; the valves glow while the page shows it. Use it as a hero or section centrepiece, never as decoration with no figure on the dial.
