# Button

Buttons start an action: a primary in solid brick for the one thing a page wants done, a ghost for everything beside it.

- Provide: a `<button>` (or an `<a>` that navigates) with class `fd-btn` plus `fd-btn--primary` or `fd-btn--ghost`, and a verb as its label ("Run it yourself", "Copy", "Read the docs").
- One primary per view. Text on brick is `on-accent`, never white: white on dark-theme brick is 3.4:1.
- Label in mono, sentence case, no exclamation marks, no icons that only decorate.
